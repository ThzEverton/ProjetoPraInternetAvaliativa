# Cadastro de Produtos — Programação para Internet

Aplicação acadêmica em Node.js criada para praticar autenticação por sessão, cookies e cadastro de produtos.

## Funcionalidades

- Login e logout
- Sessão com tempo de expiração
- Cookie de último acesso
- Menu protegido
- Cadastro de produtos
- Validação dos campos do formulário
- Listagem dos produtos cadastrados
- Interface baseada em Bootstrap

## Stack

- Node.js
- Express
- express-session
- cookie-parser
- HTML
- Bootstrap
- JavaScript ES Modules

## Executando

```bash
npm install
npm start
```

## Contexto

Projeto avaliativo da disciplina de Programação para Internet. Os dados são mantidos em memória e a autenticação é simplificada para fins didáticos, portanto a aplicação não deve ser tratada como solução de produção.
